# Dataset

Place your cleaned 303-row Cleveland heart disease CSV here as:

`heart_disease_clean.csv`

The dashboard can also load the same CSV through its Upload CSV button. The expected columns are:

`age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal, target`

The project uses the Cleveland subset of the UCI Heart Disease dataset (303 instances). Keep the dataset you used for your Tableau workbook so the web dashboard and Tableau results remain consistent.
