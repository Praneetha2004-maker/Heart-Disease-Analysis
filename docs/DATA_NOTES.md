# Data Notes

- Population: 303 Cleveland heart disease records.
- `target`: 0 = no disease; values 1–4 in the original UCI Cleveland target indicate disease presence. This project uses a binary 0/1 representation.
- `sex`: 0 = female, 1 = male.
- `cp`: 1 typical angina, 2 atypical angina, 3 non-anginal pain, 4 asymptomatic.
- `fbs`: 0 = fasting blood sugar <=120 mg/dl, 1 = >120 mg/dl.
- `exang`: 0 = no exercise-induced angina, 1 = yes.
- `slope`: 1 upsloping, 2 flat, 3 downsloping.
