# Project Workflow

1. Obtain the Cleveland heart disease dataset.
2. Prepare and inspect the data using Pandas.
3. Convert the target to a binary disease flag for analysis.
4. Create descriptive categories such as Gender, Age Group, Chest Pain Type, FBS Category, Exercise Angina, and ST Slope.
5. Build Tableau worksheets and two dashboards.
6. Use the React dashboard for an interactive web presentation of the same dataset.
7. Keep the CSV, notebook, Tableau workbook, source code, and documentation together for GitHub.
